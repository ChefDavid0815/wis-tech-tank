# Changelog / 版本记录

## 0.2.0 — 2026-09-19

First public web/source publication of the existing 0.2 classroom prototype. / 现有 0.2 课堂原型首次公开网页与源码发布。

- Nine simulated environments, 3D scene, adjustable walking speed and feedback, guided demo. / 九种模拟环境、三维场景、速度与反馈调节、自动演示。
- Chinese/English speech and UI, visible haptic patterns and exportable decision log. / 双语界面与提示、振动波形、可导出的判断记录。
- Optional local object detection, structure candidates, relative-depth worker and camera-relative map. / 可选本地物体检测、结构候选、相对深度与局部环境图。
- Vercel static deployment, bilingual documentation and natural-art portfolio exhibition. / Vercel 静态部署、双语文档与自然主题展柜。

Classroom prototype. No physical-hardware or real-world navigation validation. See VERIFICATION.md. / 课堂原型，未验证实体硬件和现实导航用途。
